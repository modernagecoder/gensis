Pick Your Track

Four distinct challenges. Choose one. Go deep. Each track expects a production-grade prototype — not a wireframe.

LLM Browser Automation Telemetry Closed-Loop

The Problem

LLMs write code blind — syntactically valid but semantically broken. Blank canvases, dead game loops, untriggered colliders, impossible win states. The root cause: there is no automated sensory or verification loop. The model can't see what it built.

Your Mission

Build an end-to-end autonomous agent that writes, tests, and self-heals a playable 2D game from a single natural-language prompt — without human intervention.

Technical Scope

Needs an autonomous playtesting harness verifying movement, collision detection, scoring, and win/loss states. The self-healing pipeline must intercept runtime telemetry, diagnose the specific failure mode, patch the code, and re-run tests — with no human in the loop.

Cryptography C2PA Validation Provenance

The Problem

Standards like C2PA attach signed provenance (creator, device, timestamp, edit history) to media files. But validators can be fooled — accepting a signature that is mathematically valid even though its signing key was later revoked, missing replayed or manipulated timestamps, or failing to flag "pipeline injection" where a real signing chain certifies AI-modified content.

Your Mission

Build a hardened validator layer that catches these gaps. Focus on one strong security feature executed with rigour — e.g. key revocation enforcement, timestamp/replay consistency checking, or suspicious edit-history detection.

Technical Scope

Scope tip: pick ONE of the following and do it really well — (a) key revocation enforcement, (b) timestamp/replay consistency checks, or (c) suspicious edit-history anomaly detection. A shallow implementation of all three scores lower than a deep, rigorous implementation of one.

Playwright DOM Analysis Security Middleware

The Problem

Autonomous browser agents can be trivially tricked by deceptive UI. Invisible overlays hijack a "Close" click into "Download malware". Clickjacking layers a malicious action behind an innocent-looking button. Pre-checked subscription traps, deceptive consent banners, and prompt injection hidden in page text can redirect an AI agent's entire task without its awareness.

Your Mission

Build a middleware "bodyguard" that sits between the agent and the browser, analyzing DOM structure and element geometry, then validating actions before they execute — blocking deceptive, injected, or manipulated instructions.

Technical Scope

MVP is achievable with Playwright + DOM inspection + event interception. Your bodyguard must detect at least: invisible overlay hijacking, clickjacking geometry mismatches, and prompt injection in visible page text. A working demo against a real deceptive-UI test page is required.

Graph Algorithms Trust Propagation PageRank Community Detection

The Problem

Sybil attacks flood a network with fake accounts that heavily interconnect with each other but attach to the real network through only a narrow "bottleneck" of connections. The structural signature is distinctive — but most detection systems rely on content, phone numbers, or photos. This track strips all of that away.

Your Mission

Build a trust-propagation or graph-analysis engine that scores nodes by trustworthiness — starting from seed "trusted" nodes — and flags low-trust clusters as Sybil suspects. Graph topology only. No names, messages, photos, or phone numbers.

Detection Pipeline

Graph Input
Seed Trusted Nodes
Trust Propagation
Score Nodes
Flag Sybil Clusters

Technical Scope

Suggested approaches: personalized PageRank, community detection (Louvain, spectral), graph cuts, or random-walk trust diffusion. The challenge is mathematically rich but computationally manageable at hackathon scale — a synthetic graph of 10,000–100,000 nodes is sufficient for a compelling demo.
